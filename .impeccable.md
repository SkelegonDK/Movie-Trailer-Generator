## Design Context

### Users
Creative hobbyists using the app as a playful creative tool or for marketing. They want to turn movie ideas into scripts, posters, narration, and downloadable trailers with little friction.

### Brand Personality
Fun, playful, approachable. The interface should make experimentation enjoyable and keep the next action obvious.

### Aesthetic Direction
High-end black and white, tailored to creative hobbyists: refined but playful. Use a calm cinema-studio aesthetic, restrained Motion transitions, and the monochrome React Bits PixelBlast background. Crisp sans-serif typography, small editorial labels, fine borders, and flat controls provide the studio finish; playful copy preserves the app’s character. The generator uses a single-page slideshow workflow with sliding sections and Back/Next controls. Successful generation advances automatically, while context, parameters, title, and generation status remain in a persistent details panel; the script stays in its own section.

### Design Principles
- Put ease of use first: clear labels, useful empty states, and visible progress.
- Keep the experience fun without letting decoration compete with the workflow.
- Align repeated controls and use the shared components and semantic tokens.
- Make keyboard navigation, contrast, and touch controls dependable.
- Keep polish focused; preserve the established visual direction.
